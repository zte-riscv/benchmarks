# biogo-igor Benchmark Assets

The biogo-igor benchmark requires an input GFF formatted file which represents
DNA strand annotations.

The file in this directory was produced by the
[biogo/krishna](https://github.com/biogo/examples/tree/master/krishna) example
using data which represents homo sapiens chromosome 22 which was retrieved in
FASTA format from [Ensembl](http://ensembl.org). Ensembl provides this data in
good faith for use without restriction (see [this
disclaimer](https://ensembl.org/info/about/legal/disclaimer.html).
