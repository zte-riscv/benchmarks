# biogo-krishna Benchmark Assets

The biogo-krishna benchmark requires an input FASTA formatted file to perform
pairwise alignment against itself.

For this purpose we include the mus musculus (a mouse) nonchromosomal DNA data
which was retrieved from [Ensembl](http://ensembl.org). Ensembl provides this
data in good faith for use without restriction (see [this
disclaimer](https://ensembl.org/info/about/legal/disclaimer.html).
